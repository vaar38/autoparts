# Магазин автозапчастей — система заказов

Консольная информационная система на Java 17 + PostgreSQL (JDBC).
Контрольная работа 1, вариант «Магазин автозапчастей (заказ автозапчастей)».

## Что нужно установить

| Программа | Версия | Проверка в терминале |
|-----------|--------|----------------------|
| JDK (Java) | 17 или новее | `java -version` |
| PostgreSQL | 14 или новее | служба PostgreSQL запущена |


## Запуск по шагам (Windows, PowerShell)

Все команды выполняются в папке проекта (там, где лежит `pom.xml`).

**1. Создать базу данных и заполнить её тестовыми данными**

```powershell
psql -U postgres -c "CREATE DATABASE autoparts"
psql -U postgres -d autoparts -f sql/autoparts.sql
```

`psql` спросит пароль пользователя `postgres`, который вы задавали при установке PostgreSQL.
Если команда `psql` не найдена, используйте полный путь, например
`& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres ...`.

Скрипт `sql/autoparts.sql` можно запускать повторно — он пересоздаёт таблицы и возвращает исходные тестовые данные.

**2. Создать `db.properties` со своим паролем**

Скопируйте образец `db.properties.example` в файл `db.properties` (в той же папке):

```powershell
Copy-Item db.properties.example db.properties
```

Откройте `db.properties` и впишите свой пароль. Этот файл не загружается в git (указан в `.gitignore`),
поэтому пароль останется только на вашем компьютере.

```properties
db.url=jdbc:postgresql://localhost:5432/autoparts
db.user=postgres
db.password=ВАШ_ПАРОЛЬ
```

**3. Собрать проект**

```powershell
.\mvnw.cmd clean package
```

В папке `target` появится файл `autoparts-team.jar` — программа вместе со всеми библиотеками.

**4. Запустить**

```powershell
.\run.cmd
```

`run.cmd` сам включает кодировку UTF-8 (чтобы русские буквы не превращались в «кракозябры»)
и находит Java: через `JAVA_HOME`, `PATH` или Java, встроенную в расширение Java для VS Code.
Можно запускать и напрямую: `java -jar target/autoparts-team.jar` (тогда сначала выполните `chcp 65001`).

Программу нужно запускать из папки проекта, потому что она читает `db.properties` из текущей папки
и сохраняет экспорт в папку `exports`.


## Структура проекта

```
autoparts/
├── pom.xml                      — описание проекта и библиотек для Maven
├── db.properties                — параметры подключения к базе
├── sql/autoparts.sql            — SQL-скрипт: таблицы + тестовые данные
├── docs/
│   ├── er-diagram.md            — ER-диаграмма базы данных
│   └── GUIDE.md                 — подробное объяснение кода для защиты
├── exports/                     — сюда сохраняются Excel/CSV файлы
└── src/main/java/ru/mirea/autoparts/
    ├── Main.java                — точка входа: собирает все слои и запускает меню
    ├── model/                   — сущности: Customer, Order, enum OrderStatus, PartCategory
    ├── repository/              — работа с БД через JDBC (весь SQL здесь)
    ├── service/                 — бизнес-логика, фильтрация, сортировка, статистика
    ├── exception/               — собственные исключения
    ├── util/                    — подключение к БД и экспорт в Excel/CSV
    └── ui/                      — консольные меню и ввод с клавиатуры
```

## Возможные проблемы

| Сообщение | Что делать |
|-----------|------------|
| `Не удалось подключиться к базе данных ... password authentication failed` | Неверный пароль в `db.properties` |
| `... database "autoparts" does not exist` | Не выполнен шаг 1 (создание базы) |
| `Connection refused` | Не запущена служба PostgreSQL (Win+R → `services.msc` → postgresql → Запустить) |
| `Не удалось прочитать файл настроек db.properties` | Программа запущена не из папки проекта |
| Русские буквы в консоли отображаются «кракозябрами» | Запускать через `.\run.cmd` (или выполнить `chcp 65001` перед `java -jar`) |
